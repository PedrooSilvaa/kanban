# Kanban API

API de um sistema **Kanban** desenvolvida em **Java** e **Spring Boot**, utilizando um banco de dados relacional **MySQL**.  

A API permite **salvar**, **listar por status**, **alterar status** e **deletar tarefas por ID**.

## 🚀 Tecnologias Utilizadas

- **Java**: Linguagem principal do projeto.
- **Spring Boot**: Framework para construção da API.
- **MySQL**: Banco de dados relacional para armazenar as tarefas.
- **JPA/Hibernate**: ORM para manipulação dos dados.
- **Spring Web**: Para criação dos endpoints REST.

## ✨ Funcionalidades

- **Criar Tarefa**: Salva uma nova tarefa no banco de dados.
- **Listar Tarefas por Status**: Filtra as tarefas pelo status (ex: "A Fazer", "Em Progresso", "Concluído").
- **Alterar Status da Tarefa**: Atualiza o status de uma tarefa existente.
- **Deletar Tarefa**: Remove uma tarefa pelo ID.
